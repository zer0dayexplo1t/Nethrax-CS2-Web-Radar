# Security

This repository contains **no product source code, binaries, or credentials**.

- Do not open issues asking for cracks, shared accounts, or leaked builds.
- Report phishing / fake Discord invites to staff in the official server.
- Official entry point: Discord only (link in the README).

Nethrax access is device-bound. Sharing seats, HWIDs, or builds is a permanent ban.

If you believe you found a security issue with the membership platform, contact staff via an official Discord ticket.
